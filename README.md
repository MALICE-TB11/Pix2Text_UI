# Pix2Text 公式识别小工具

把公式截图（或图片）拖进浏览器页面，自动识别成 LaTeX 代码并复制到剪贴板。基于开源项目 [Pix2Text](https://github.com/breezedeus/Pix2Text)，**全部在本机运行**，图片不会上传到任何服务器。

## 文件说明

| 文件 | 作用 |
|---|---|
| `start_p2t.bat` | 启动器。首次运行自动安装，之后双击即可启动 |
| `p2t_ui.py` | 识别程序和网页界面 |
| `README.md` | 本说明 |

首次运行后会多出一个 `p2t_env` 文件夹，是工具自己的 Python 环境，不会影响电脑上其他 Python。

## 快速开始

1. **先解压 zip**，不要直接在压缩包里双击运行。
2. 确认电脑装有 **Python 3.9 到 3.13**（推荐 3.12）。没装的话去 <https://www.python.org/downloads/> 下载，安装时务必勾选 **Add python.exe to PATH**。
3. 双击 `start_p2t.bat`。
4. **首次运行**会自动安装依赖（下载约 1 到 3 GB，5 到 15 分钟），期间不要关闭黑色窗口。
5. 安装完成后会自动启动，并在浏览器中打开 `http://127.0.0.1:8504`。第一次启动还会下载识别模型，需要再等几分钟。
6. 以后每次使用，直接双击 `start_p2t.bat`，加载模型约十几秒。

用完关闭黑色窗口即可退出。

## 界面用法

- **输入图片**：把图片拖进虚线框、点击虚线框选择文件，或者直接 `Ctrl+V` 粘贴。用 `Win+Shift+S` 截图后马上粘贴最方便。
- **识别模式**：
  - 仅公式：图片里只有一个公式，识别最准。
  - 文字 + 公式混合：一段文字里夹着公式，输出 Markdown。
- **界面语言**：页面会按浏览器语言自动显示中文或英文，右上角的下拉框可以手动切换，选择会被记住。黑色窗口里的提示也会跟随系统语言。
- **自动复制**：识别完成后默认把 LaTeX 复制到剪贴板，可以取消勾选。
- **三个复制按钮**：纯 LaTeX、`$...$`（行内）、`$$...$$`（独立公式）。
- **结果框可手动修改**，下面的渲染预览会同步刷新，用来对照原图检查。

### 提高识别准确率

- 截图只框住公式本身，周围留白少一点。
- 图片要清晰，分辨率太低容易识别错。
- 识别后务必对照原图核对，常见错误有 `l` 和 `1`、`0` 和 `O`、上下标位置、括号配对。
- 手写公式的准确率比印刷体低。

## 常见问题

**双击后提示找不到 Python**
安装 Python 3.12，并勾选 "Add python.exe to PATH"，然后重新运行。

**提示找不到 p2t_ui.py**
让 `p2t_ui.py` 和 `start_p2t.bat` 在同一个文件夹里。启动器会先找自己所在的文件夹，找不到再去桌面、下载、文档里搜索。

**安装很慢或失败**
用记事本打开 `start_p2t.bat`，在文件开头找到下面两行，删掉行首的 `rem `，保存后重新运行：

```
rem set "PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple"
rem set "HF_ENDPOINT=https://hf-mirror.com"
```

第一行让 pip 使用清华镜像，第二行让模型从 HuggingFace 镜像下载。

**报错 `cannot import name 'resolve_model_key'` 或 `'EngineType'`**
这是 `rapidocr` 版本和 `cnstd` 不匹配。启动器会在首次安装时自动逐个尝试版本，一般不需要手动处理。

**报错 `CUDAExecutionProvider ... available providers are ['CPUExecutionProvider']`**
公式模型在 CPU 上运行，程序检测到 GPU 不可用时会自动回退到 CPU，不用处理。CPU 识别单个公式通常只要几秒。

**渲染预览区显示"KaTeX 未加载"**
预览用到的 KaTeX 从 `cdn.jsdelivr.net` 加载，网络访问不了时无法预览，不影响识别和复制。

**8504 端口被占用**
程序会自动顺延尝试 8505 到 8513，看黑色窗口里打印的地址即可。也可以在命令行里设置环境变量 `P2T_PORT` 指定起始端口。

**想重新安装**
关闭程序，删除 `p2t_env` 文件夹，再双击 `start_p2t.bat`。

**想卸载**
直接删除整个文件夹。模型缓存在用户目录下的 `.pix2text`、`.cnstd`、`.cnocr` 以及 `.cache\huggingface` 文件夹里，需要的话可以一并删除。

## 进阶

- **使用 GPU 版 PyTorch**：把 `start_p2t.bat` 开头的 `set "USE_GPU=0"` 改成 `1`，再删除 `p2t_env` 重新安装。这需要 NVIDIA 显卡，下载约 3 GB。公式识别模型本身仍走 CPU（ONNX），所以对这个工具的速度提升有限，一般不需要。
- **只允许本机访问**：服务只绑定在 `127.0.0.1`，局域网内其他设备无法访问。
- **命令行直接使用 Pix2Text**：进入 `p2t_env\Scripts` 后运行 `python` 即可使用该环境里的 `pix2text` 包。

## 说明

- 本工具只是 Pix2Text 的一个本地界面封装，识别能力来自 Pix2Text 及其依赖的开源模型，请遵守各项目的开源协议。
- 主要在 Windows 10/11 + Python 3.12 下开发调试，其他 Python 版本和系统未全面验证。
- 识别结果可能有误，用于论文或作业前请逐项核对。
